**Tech:** Python

Secure OTP system that generates a 6-digit OTP, emails it

## How to Run
Each file is independent. Run any file directly:
```bash
python chatbot.py
python expense-tracker.py
python otp-generator.py
python web_scraper_.py
```

## Tech Stack
- Python 3
- Libraries: requests, BeautifulSoup, smtplib, 
  phonenumbers, pywhatkit, qrcode, barcode, tkinter
